# Conjugation tables in the database

About 2,060 verbs (every verb in `vocabulary.csv`, plus 97 reflexive verbs such as *se laver*), each with
présent, imparfait, futur, conditionnel, subjonctif présent, impératif and participe passé, kept in two
tables so the app can conjugate any verb and **find a verb from any of its forms** (*mangeons*,
*ai mangé*, *irons*), with no AI.

**Until you run this, nothing breaks:** the Conjugations page keeps using its built-in 296 verbs.

## Run the SQL (about 5 minutes)

Supabase → **SQL Editor** → **New query**, then paste and **Run** each file in this order:

1. `01_conjugations.sql`: creates the tables and the read rules. You should see `verbs = 0, forms = 0`.
2. `02_verbs_part1.sql`, `02_verbs_part2.sql`, `02_verbs_part3.sql`, `02_verbs_part4.sql`: the verbs, in any
   order. Each ends with a running count; after the fourth you should see about 2,060.
3. `03_forms.sql`: builds the list of forms to search. You should see about 2,060 verbs, about 66,000 forms,
   and a small table showing **manger** for the test search *mangeons*.

Every file is safe to run again. `03_forms.sql` rebuilds the forms from the verbs each time.

## How the tables look

| Table | One row per | Main columns |
|---|---|---|
| `conjugation_verbs` | verb | `inf`, `english`, `ending` (er/ir/re/oir), `grp` (1, 2, 3), `pronominal`, `aux`, `pp`, `forms` (JSON: `p`, `im`, `f`, `c`, `s` = six forms, `ip` = tu, nous, vous), `note` |
| `conjugation_forms` | form | `inf`, `tense`, `person`, `form`, `form_plain` (no accents, lower case) |

Signed-in students can read both tables and nothing else; nobody can change them from the app.
To correct a form: Table Editor → `conjugation_verbs` → edit the `forms` JSON, then run `03_forms.sql` again.

The forms were generated by rules plus hand-written irregular verbs and checked by eye, not against a
published reference, so rare verbs may have small errors. Corrections are welcome.

## Look up a form from SQL

```sql
select inf, tense, person, form
from "French-schema".conjugation_forms
where form_plain = "French-schema".plain_text('ai mangé')   -- one word: use the last word, 'mange'
order by inf;
```
