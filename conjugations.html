Tense notes

Three stems build almost every tense: the infinitive (future stem), the nous form and the ils form.

Stems

  • Infinitive ✓ → stays the same (parler, finir, vendre): used after aller, venir de (d'), en train de (d')
  • Future stem: er, ir → the infinitive (parler-, finir-); re → r (vendre → vendr-)
    • Irregular future stems: être → ser-, avoir → aur-, aller → ir-, faire → fer-, venir → viendr-, pouvoir → pourr-, vouloir → voudr-, devoir → devr-, savoir → saur-, voir → verr-, falloir → faudr-
  • nous stem: nous form − ons (venons → ven-) → the imparfait, and nous / vous in the subjonctif
    • Spelling change before a / o: -ger → -ge- (je mangeais), -cer → -ç- (je commençais)
  • ils stem: ils form − ent (viennent → vienn-) → the subjonctif
  • Past participle: er → é, ir → i, re → u
    • Irregular: être → été, avoir → eu, faire → fait, prendre → pris, mettre → mis, dire → dit, écrire → écrit, voir → vu, venir → venu, ouvrir → ouvert, mourir → mort, naître → né

Everyday tenses

  • Présent progressif → être + en train de (d') + infinitive (il est en train d'écouter) (I am in the middle of doing)
  • Passé récent → venir de (d') + infinitive (je viens d'arriver) (I have just done)
  • Futur proche → aller + infinitive (I am going to do)
  • Impératif → the présent of tu / nous / vous (do! / let's do!)
    • -er verbs and aller drop the s in the tu form: Parle ! Va !
    • Irregular: être → sois, avoir → aie, savoir → sache, vouloir → veuille / veuillez (Veuillez patienter. Veuillez agréer…: common in TCF listening and formal letters)
  • Passé composé → avoir / être + past participle (I did / I have done)
    • Use être with:
      • the 17 DR & MRS VANDERTRAMP verbs: devenir, revenir, monter, rester, sortir, venir, aller, naître, descendre, entrer, rentrer, tomber, retourner, arriver, mourir, partir, passer (and their compounds: redevenir, remonter, repartir…)
      • all reflexive verbs: je me suis levé(e), elle s'est promenée
    • With être, the past participle agrees with the subject: elle est allée, ils sont partis, elles sont venues
    • Exception: monter, descendre, sortir, rentrer, retourner and passer take avoir when they have a direct object: je suis sorti → j'ai sorti la poubelle; je suis monté → j'ai monté les valises
    • Everything else uses avoir, including être and avoir themselves: j'ai été, j'ai eu
    • Memory hook: a house 🏠: you're born, arrive, enter, go up, stay, come down, fall, go out, leave and die

Built from the basic forms

  • Imparfait → nous − ons + imparfait endings (I was doing / I used to do)
    • Exception: être → ét- (j'étais)
  • Plus-que-parfait → imparfait of avoir / être + past participle (I had done)
  • Conditionnel → future stem + imparfait endings (I would do)
  • Conditionnel passé → conditionnel of avoir / être + past participle (I would have done)
  • Futur simple → future stem + future endings (I will do)
  • Futur antérieur → futur of avoir / être + past participle (I will have done)
  • Subjonctif → que + ils − ent + subjonctif endings (that I do: after il faut que, je veux que…)
    • nous / vous use the nous stem: que nous venions, que vous veniez (but que je vienne)
    • Irregular: être → sois, avoir → aie, aller → aille (que nous allions), faire → fasse, pouvoir → puisse, savoir → sache, vouloir → veuille (que nous voulions)
  • Subjonctif passé → que + subjonctif of avoir / être + past participle (that I have done)

Every compound tense follows the same être rules as the passé composé: elle était partie, elle serait venue. So does the infinitif passé: avoir / être + past participle (après avoir mangé, après être arrivé(e)).

Regular -ir only

  • The -iss- (finissons, finissais, que je finisse, finissant) is only for regular -ir verbs like finir and choisir.
  • Irregular -ir verbs (partir, dormir, sortir, ouvrir) drop it and work like -er / -re verbs: je partais, que je parte, partant.

Accents count, but you'll be told if only an accent is missing. Tip: (e) and (s) mean you can write either form.
